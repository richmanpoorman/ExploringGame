| **Runner Signals**                                                                                                                       |
|------------------------------------------------------------------------------------------------------------------------------------------|
| ModelRunner                                                                                                                              |
|------------------------------------------------------------------------------------------------------------------------------------------|
| *Name*           | *Arguments*                                   | *Description*                                                         | 
|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| change_model     | modelViewController : ModelViewControllerData | Changes the model to the one in data pack, and forwards the change to |
|                  |                                               | the ControllerRunner to also update the Controller                    | 
|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| [Any Signal]     | to : string = "model"                         | Sends the signal to the underlying model [Only used by ModelRunner]   |
|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| [Any Signal]     | to : string = "controller"                    | Sends the signal from the ModelRunner to the                          |
|                  |                                               | registered ControllerRunner                                           |
|------------------------------------------------------------------------------------------------------------------------------------------|
| ControllerRunner                                                                                                                         |
|------------------------------------------------------------------------------------------------------------------------------------------|
| *Name*           | *Arguments*                                   | *Description*                                                         | 
|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| change_model     | modelViewController : ModelViewControllerData | Changes the controller to the one in data pack, and forwards the      |
|                  |                                               | change to the ViewController to also update the view                  | 
|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| [Any Signal]     | to : string = "controller"                    | Sends the signal to the underlying controller                         | 
|                  |                                               | [Only used by ControllerRunner]                                       |
|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| [Any Signal]     | to : string = "model"                         | Sends the signal from the ControllerRunner to the                     |
|                  |                                               | registered ModelRunner                                                |
|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| [Any Signal]     | to : string = "view"                          | Sends the signal from the ControllerRunner to the                     |
|                  |                                               | registered ViewRunner                                                 |
|------------------------------------------------------------------------------------------------------------------------------------------|

|------------------------------------------------------------------------------------------------------------------------------------------|
| *Name*           | *Arguments*                                   | *Description*                                                         |

|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| [Any Signal]     | to : string = "view"                          | Sends the signal to the underlying view [Only used by ViewRunner]     |
|------------------|-----------------------------------------------|-----------------------------------------------------------------------|
| [Any Signal]     | to : string = "controller"                    | Sends the signal from the ViewRunner to the                           |
|                  |                                               | registered ControllerRunner                                           |
